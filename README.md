# sr_trashsystem

A simple trash system for FiveM.

Walk up to any trash bin, open it, and drop the items you want to get rid of. Once you close it, everything inside is gone. Each trash is personal and temporary, nothing is saved.

## Requirements

- ox_lib
- ox_inventory
- ox_target

## Config

In `config.lua` you can set:

- `language` the locale to use (`en`, `ar`, `fr`, `de`, `es`)
- `maxDistance` how close the player has to be to the bin
- `stash` how many slots and how much weight each trash can hold
- `models` the props that can be used as trash bins

## Languages

English, Arabic, French, German and Spanish.
